# US Visa Appointment Scheduler v2.0

基于AIS插件核心逻辑的高级美签预约重调度器。

## 核心功能

### 🔐 自动登录

- 支持保存用户名/密码
- 自动处理登录流程
- 会话保持和恢复

### 🎯 智能预约检查

- 实时监控更早的预约日期
- 支持多个预约中心
- ASC预约自动处理
- 自定义日期范围筛选

### 🚀 页面导航

- 自动识别页面类型
- 智能页面跳转
- 预约流程自动化

### 📊 监控功能

- 可配置检查间隔
- 实时状态显示
- 预约可用性通知
- 错误处理和重试

## 使用说明

### 1. 初始设置

1. 在扩展弹窗中点击"设置"
2. 输入美签网站的用户名(邮箱)和密码
3. 设置默认预约中心编号
4. 保存配置

### 2. 开始监控

1. 打开美签预约页面 (ais.usvisa-info.com)
2. 确保已登录并进入预约页面
3. 在扩展弹窗中设置预约中心编号
4. 选择检查间隔 (建议1-2分钟)
5. 点击"开始监控"

### 3. 自动处理

- 扩展会自动检查更早的预约日期
- 发现可用预约时会发送通知
- 在预约页面会自动填写表单
- 支持ASC预约自动安排

## 故障排除

### 常见问题

**Q: 扩展无法开始监控？**
A: 确保在正确的页面（预约页面），并且已配置用户名密码

**Q: 没有收到通知？**
A: 检查浏览器通知权限设置

**Q: 监控停止了？**
A: 可能是网络问题或登录过期，重新登录后重试

**Q: 找不到预约？**
A: 检查预约中心编号是否正确，以及日期范围设置

### 重置扩展

如果遇到问题，可以在设置页面点击"重置扩展"清除所有数据重新开始。

## API 参考

基于原notes.md中的API文档：

### 获取可用日期

```
GET /schedule/{scheduleId}/appointment/days/{locationId}.json?appointments[expedite]=false
```

### 获取可用时间

```
GET /schedule/{scheduleId}/appointment/times/{locationId}.json?date={date}&appointments[expedite]=false
```
